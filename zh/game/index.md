# 游戏逻辑

## 核心规则

### 回合流程

1. 投掷骰子
2. 移动棋子（逐格动画）
3. 到达目标格子触发事件
4. 购买/支付/抽卡
5. 回合结束

### 地皮系统

- 初始价格：50-400 不等
- 房屋：每栋 50，最多 4 栋
- 租金：基于房屋数量计算

### AI 决策 (aiBrain.js)

AI 使用评分系统决策是否购买地皮：

```javascript
// 评分考虑因素
- 资金余额
- 对手持有同色组数量
- 地皮位置（靠近起点价值更高）
- 当前回合数
- 风险评估
```

### 成就系统

基于以下维度的成就：
- 对局次数
- 持有资产
- 连续获胜
- 特定主题棋盘完成

## 地图编辑器 (EditorPage.jsx)

拖拽式棋盘编辑器，支持：
- 添加/删除地皮
- 修改地皮属性（价格、租金）
- 切换主题
- 保存/加载布局
